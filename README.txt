Source

Dictionary entries were extracted from pages 8–222 of the supplied PDF. Appendix pages were not included in the searchable database.

Entries extracted: 4185

Local testing
-------------
Because browsers may block fetch() when index.html is opened directly from a file, the most reliable test is GitHub Pages. Alternatively, use a simple local web server.

GitHub Pages
------------
1. Create a GitHub repository.
2. Upload index.html, style.css, script.js, and dictionary.json.
3. In Settings → Pages, choose the main branch/root folder.
4. Save and open the GitHub Pages URL.
